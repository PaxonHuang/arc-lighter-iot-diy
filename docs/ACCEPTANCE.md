# 项目验收清单

## ✅ 功能验收
- [ ] M100PG-C2 DTU 上电后 NET LED 1000ms 慢闪(联网)
- [ ] 银尔达 IOT 平台显示设备**在线**
- [ ] Web 端切换 `sw1` 数据点 → 设备继电器吸合(听"咔哒"声)
- [ ] 电弧产生:电极间隙有可见电弧
- [ ] Web 端切换 `sw1` 回 0 → 设备继电器释放,电弧熄灭
- [ ] Arduino 本地按键 → LED 切换 + 蜂鸣器响
