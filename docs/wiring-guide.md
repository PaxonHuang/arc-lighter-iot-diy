# 接线指南 — M100PG-C2 电弧点火机（v2，2026-08-31 修订）

> v2 修订原因：2026-08-31 实测 `config,set,doout,1,1` 经 MQTT 下发返回 `config,doout,error,2`（串口本地同样如此，见 §1.3）。
> 依据《DTU指令手册/6、硬件资源命令》"只有硬件引出这些资源的，才有对应的命令"，以及 M100PG-C2 引脚表（仅 VIN/GND/TXD/RXD/DTR/RST/RDY/1PPS，**无 DO/继电器引脚**），确认：
> **M100PG-C2 不支持 doout 数字输出。继电器改由 Arduino UNO D7 驱动，DTU 任务通过 UART 下发 `relay:1/relay:0` 命令。**
> v1 版 SPEC §5.1 中"继电器 IN ← M100PG-C2 doout"的接法作废。

## 0. 系统总览与信号流

```
                     ┌─────────────────────────────────────────────┐
                     │                18650 电池(1S, 3.0~4.2V)      │
                     └───────┬───────────────┬─────────────────────┘
                             │ 电池+          │ 电池−(公共GND ★)
              ┌──────────────┘               │
              ▼                              ▼
        M100PG-C2 VIN                  继电器 COM(公共端)
       (直连, 3.3~4.2V 区间)                │ 吸合时导通
              │                            ▼
              │ UART(9600)            XL6009 VIN+ ──(升压到24V,预热时整定)
    TXD ──────┼──→ UNO D0(RX)              │
    RXD ←─────┼─── UNO D1(TX)         D880 振荡电路 → 高压线圈 → 电弧电极
              │
   继电器控制权: UNO D7 ──→ 继电器模块 IN(高电平触发)
   UNO 供电:    电池+ ──→ MT3608 升压整定 5.0V ──→ UNO 5V脚 + 继电器 VCC
   本地人机:    D2按键 / D4 LED / D8 蜂鸣器
   预留:        UNO D6 ──→ DTU RST(异常恢复,固件暂未启用)
   调试口:      UNO D5(SoftwareSerial TX) ──→ USB-TTL RX ──→ 电脑(看日志)
```

控制链（远程开→关弧）：云端/任务 → DTU task.lua → UART `relay:1\n` → UNO → **D7 拉高** → 继电器吸合 → 电池+ 接通 XL6009 → 高压振荡 → 电弧。

## 1. 实测结论（2026-08-31，指导本次修订）

### 1.1 串口本地配置命令一切正常
YEDTestTools 桌面客户端实测（固件 `YED_DTU3_1.1.21`）：
- `config,get,imei` → `ok,864865083079369`
- `config,get,iccid` / `firmwarever` / `netstatus,1=1`（通道1已连上测试服务器）
- `config,set,location` / `gps`、`config,set,save` 均正常

### 1.2 MQTT 远程 config 命令的两类报错
| 现象 | 原因 | 处置 |
|---|---|---|
| `config,imei\r\n,error,1` | 在测试工具的数据框里**手打了字面 `\r\n` 字符**，设备把 `imei\r\n` 当成了命令名，格式错（error,1 = 命令/格式错误） | 数据框只填 `config,get,imei`，换行交给工具的"回车换行"选项自动补 |
| `config,doout,error,2` | M100PG-C2 **无 DO 硬件资源**，doout 命令不被支持（error,2 = 资源/命令不支持） | 本指南 v2：继电器改由 UNO D7 驱动；task.lua 去掉 PerSetDo |

### 1.3 需要核对的一处疑点
平台三要素 ClientID 后缀为 `864865083679369`，设备实测 IMEI 为 `864865083079369`——**第 10 位差一个数字**。请到 iot.yinerda.com 设备详情核对：若平台记录的 IMEI 与设备不符，删除设备用正确 IMEI 重新添加并重新获取三要素（否则通道1指向 IOT 平台后可能连不上/鉴权异常）。若平台页面显示一致则只是粘贴笔误，三要素按平台下发原样使用即可。

## 2. 器件与引脚表

### 2.1 M100PG-C2（DTU）
| DTU 引脚 | 接到 | 说明 |
|---|---|---|
| VIN | 18650 电池 +（经开关，见 §3.1） | 3.3~4.2V 直连，**不可接 5V** |
| GND | 公共 GND ★ | |
| TXD | UNO D0 (RX) | 3.3V 电平，UNO 可识别（VIH≥3.0V，实测可用） |
| RXD | UNO D1 (TX) | 官方标注兼容 5V 电平，可直连 |
| RST | UNO D6（预留） | 官方建议 MCU 接 RST 做异常恢复，本版固件未启用 |
| 4G 天线 IPEX | 必接 | 不接天线信号极差 |
| USB | 调试/看日志/升级 | 与 TTL 串口独立 |

### 2.2 Arduino UNO R3
| UNO 引脚 | 接到 | 说明 |
|---|---|---|
| 5V | MT3608 输出 5.0V（**先整定后接入**） | 同时供继电器模块 VCC |
| GND | 公共 GND ★ | |
| D0 (RX) | DTU TXD | **烧录固件时必须拔掉这根线** |
| D1 (TX) | DTU RXD | **烧录固件时必须拔掉这根线** |

| D7 | 继电器模块 IN | 高电平触发 |

### 2.3 继电器模块（TONGLING 1 路，JQC-3FF-S-Z）

## 3. 分步装配与上电检查（按序执行，每步有检查点）

> 总原则：**先低压、后高压；先单板、后联机；全程不装 18650，用 USB/桌面电源代供**。★ 记号 = 公共 GND 星点（电池负极处单点汇接，避免高压回路电流流经信号地）。

### 步骤 1：DTU 单板（已完成 ✅）
用 DTU 自身 USB 供电 + YEDTestTools 串口验证（就是你 8/31 凌晨做的部分）。确认天线已接、SIM 槽内卡片 ICCID 正常。

### 步骤 2：UNO 单板（无任何外接线）
1. 仅 USB 供电，`pio run -t upload`（见 §5 PlatformIO）烧录固件。
2. 检查点：上电 LED 灭；按 D2 按键，蜂鸣器短响、LED 亮（本地触发翻转）。
3. 再把 USB-TTL 接 D5（调试口）→ 串口助手 9600 应看到 boot/ready 及按键 JSON 事件。

### 步骤 3：MT3608 整定（**接入 UNO 之前必须做**）
1. MT3608 只接电池正负（或桌面电源 3.7V 模拟），输出空载。
2. 万用表调 VOUT 电位器到 **5.00V ±0.05V**，锁紧。
3. 检查点：拆下电池后复测一次输出仍为 5V（防止电位器松动）。升压模块空载输出可能高达输入电压以上，未整定直插会烧 UNO。

### 步骤 4：低压联机（DTU + UNO + 继电器，无 XL6009/高压）
1. 按 §2.1/2.2/2.3 接线：串口 3 线、D7→IN、5V/GND、DTU VIN←电池+（此时用桌面电源 3.8V 代供）。
2. UNO 改由 MT3608 5V 供电（拔 USB 前先接好 MT3608，再拔 USB；**5V 脚与 USB 供电不要同时接**）。
3. 检查点：DTU NET LED 正常闪烁；云端/MQTT 测试工具下发 `relay:1`（经任务）→ 听到继电器"咔哒"，LED 亮、调试口打印。
4. 上电次序：先 5V 轨（UNO/继电器）后 DTU 均可，但**撤电时先撤动力电（电池总开关）**。

### 步骤 5：XL6009 整定（仍不带 D880/线圈）
1. 继电器 COM/NO 接入 XL6009 输入，输出空载。
2. 手动短接 COM-NO 模拟吸合（或下发 relay:1），万用表调 XL6009 输出到 **24V**，锁紧。
3. 检查点：relay:0 断开后 XL6009 输入端电压为 0。

### 步骤 6：高压振荡与电极（最后装配）
1. 万能板焊 D880 振荡电路 + 高压线圈（初/次级判别：粗线为初级）。
2. 电极固定在绝缘支架上，间隙先调 **3mm**。
3. 首次试弧：**在户外或不燃托盘上**、电极朝向无人方向，下发 relay:1，观察电弧后立即 relay:0（单次 <5s）。
4. 检查点：D880 温升（烫手则加大散热片/缩短导通时间）；电弧稳定长度 2~4mm。

### 步骤 7：正式电池供电
1. 装入 18650（建议带 DW01+8205A 保护板），总开关串在电池+。
2. 复测 §4 全部检查项，记录到 `docs/experiment-log.md`。

## 4. 接线检查清单（上电前逐项打勾）
- [ ] 电池极性：DTU VIN 上实测 3.3~4.2V（红表笔 VIN、黑表笔 GND）
- [ ] MT3608 输出实测 5.0V（接入 UNO 前后各测一次）
- [ ] 串口交叉：DTU TXD→D0、DTU RXD←D1（不是并排直连）
- [ ] 所有 GND（DTU/UNO/继电器/MT3608/XL6009/高压次级）汇于一点
- [ ] 高压次级与低压部分间距 ≥10mm；高压线走线远离天线与串口线
- [ ] 4G/WiFi-GPS 天线已装（IPEX 需按压到位）
- [ ] 继电器 NC 悬空、NO 去向 XL6009，COM 接电池+
- [ ] 烧录 UNO 固件前已拔下 D0/D1

## 5. 与固件的对应关系（PlatformIO 工程）
- 固件：`firmware/arduino/arc_remote/`（PlatformIO 工程，`src/main.cpp` + `include/config.h`）
- 引脚改动集中在 `include/config.h`：`RELAY_PIN=7`（新增）、`DEBUG_TX_PIN=5`（调试口）、`DTU_RST_PIN=6`（预留）
- DTU 侧任务 `firmware/m100pg-c2/task.lua` 已同步去掉 `PerSetDo`（本机无 DO 资源），继电器完全由 UNO 驱动
- 烧录：`pio run -t upload`（拔 D0/D1）；日志：`pio device monitor` 或 USB-TTL 接 D5 看 9600 调试口
