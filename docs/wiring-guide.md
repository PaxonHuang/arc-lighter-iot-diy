# 接线指南 — M100PG-C2 电弧点火机（v3，2026-09-02 修订）

> **v3 修订（2026-09-02）**：① 移除全部蜂鸣器相关功能（固件不再使用 D8；文档删除蜂鸣描述）。② 依据商供原理图 + BOM（`img/lighter-high-Voltage-Transformer.jpg`）重写高压部分——点火模块是 **DC12V 输入的 ZVS 推挽自激振荡升压**电路，旧版"XL6009→D880 单管、24V 母线"的描述作废。ZVS 无反馈闭环，需严格限制单次通电时长并做放电安全（详见 §2.4）。
>
> v2 修订原因：2026-08-31 实测 `config,set,doout,1,1` 经 MQTT 下发返回 `config,doout,error,2`（串口本地同样如此，见 §1.3）。
> 依据《DTU指令手册/6、硬件资源命令》"只有硬件引出这些资源的，才有对应的命令"，以及 M100PG-C2 引脚表（仅 VIN/GND/TXD/RXD/DTR/RST/RDY/1PPS，**无 DO/继电器引脚**），确认：
> **M100PG-C2 不支持 doout 数字输出。继电器改由 Arduino UNO D7 驱动，DTU 任务通过 UART 下发 `relay:1/relay:0` 命令。**
> v1 版 SPEC §5.1 中"继电器 IN ← M100PG-C2 doout"的接法作废。

## 0. 系统总览与信号流

```
                     ┌─────────────────────────────────────────────┐
                     │                18650 电池(1S, 3.0~4.2V)      │
                     └───────┬───────────────┬─────────────────────┘
                             │ 电池+          │ 电池−(公共GND ★)
              ┌──────────────┘               │
              ▼                              ▼
        M100PG-C2 VIN                  继电器 COM(公共端)
       (直连, 3.3~4.2V 区间)                │ 吸合时导通
              │                            ▼
              │ UART(9600)           点火模块 DC12V/GND ──(ZVS推挽自激振荡)
    TXD ──────┼──→ UNO D0(RX)              │
    RXD ←─────┼─── UNO D1(TX)         EE16高压线圈 → 整流 → 电弧电极(~5mm)
              │
   继电器控制权: UNO D7 ──→ 继电器模块 IN(高电平触发)
   UNO 供电:    电池+ ──→ MT3608 升压整定 5.0V ──→ UNO 5V脚 + 继电器 VCC
   本地人机:    D2按键 / D4 LED(状态指示;无蜂鸣器)
   预留:        UNO D6 ──→ DTU RST(异常恢复,固件暂未启用)
   调试口:      UNO D5(SoftwareSerial TX) ──→ USB-TTL RX ──→ 电脑(看日志)
```

控制链（远程开→关弧）：云端/任务 → DTU task.lua → UART `relay:1\n` → UNO → **D7 拉高** → 继电器吸合 → 电池+ 经 MT3608 升至 12V 送点火模块 DC12V → ZVS 起振 → 高压 → 电弧。

## 1. 实测结论（2026-08-31，指导本次修订）

### 1.1 串口本地配置命令一切正常
YEDTestTools 桌面客户端实测（固件 `YED_DTU3_1.1.21`）：
- `config,get,imei` → `ok,864865083079369`

### 1.2 MQTT 远程 config 命令的两类报错
| 现象 | 原因 | 处置 |
|---|---|---|
| `config,imei\r\n,error,1` | 在测试工具的数据框里**手打了字面 `\r\n` 字符**，设备把 `imei\r\n` 当成了命令名，格式错（error,1 = 命令/格式错误） | 数据框只填 `config,get,imei`，换行交给工具的"回车换行"选项自动补 |
| `config,doout,error,2` | M100PG-C2 **无 DO 硬件资源**，doout 命令不被支持（error,2 = 资源/命令不支持） | 本指南 v2：继电器改由 UNO D7 驱动；task.lua 去掉 PerSetDo |

### 1.3 需要核对的一处疑点
平台三要素 ClientID 后缀为 `864865083679369`，设备实测 IMEI 为 `864865083079369`——**第 10 位差一个数字**。请到 iot.yinerda.com 设备详情核对：若平台记录的 IMEI 与设备不符，删除设备用正确 IMEI 重新添加并重新获取三要素（否则通道1指向 IOT 平台后可能连不上/鉴权异常）。若平台页面显示一致则只是粘贴笔误，三要素按平台下发原样使用即可。

### 2.4 点火模块（淘宝电弧点火器原理图 — ZVS 推挽自激振荡升压，见 `img/lighter-high-Voltage-Transformer.jpg`）

> v3 (2026-09-02)：以商供原理图 + BOM 为准重写。本节替代旧版"XL6009→D880 单管自激"描述。

**电路本质**：DC12V 母线经保险 F1、肖特基 D5(D6) 进入由 **Q1/Q2(SS8050)** 组成的 **ZVS 推挽自激振荡器**——T1（小磁环驱动变压器，L1:L2≈1:1）提供正反馈使两管交替导通，把 12V 斩成交流送入 T2 初级 **L3(0-7t-0-7t-0, EE16 磁芯)**；T2 次级 L4(**1050T**) 感应出高压，经 **D1–D4(FR107)** 全桥整流滤波（C4/C5/C6 高压瓷片电容）后送到电极 E。R5/R6(120k)、R7(1M) 为启动/泄放偏置。**无稳压/无反馈闭环**：通电即满功率起振。

**接线（模块对外端子）**：
| 模块端子 | 接到 | 说明 |
|---|---|---|
| DC12V(+) | 继电器 NO（母线正极） | 12V 动力输入，见 §2.5 |
| GND(−) | 公共 GND ★ | 与控制/电池负极共地 |
| 高压输出端 | 电极 A（针尖） | 经整流后的高压，间距可调 |
| 回路端 | 电极 B（板状）+ GND | 与电极 A 间隙 ~5mm（BOM 标注） |

**关键器件（BOM 摘录，详见 `hardware/bom.csv`）**：Q1/Q2=SS8050；T1=磁环驱动变 L1:L2=1:1；T2=高压变 L3 0-7t-0-7t-0 / L4 1050T（EE16）；D1–D4=FR107；D5/D6=SS54 肖特基；D7=稳压管；F1=保险丝；R1/R2=100Ω(0805)，R5/R6=120k，R7=1M；C1/C2/C3=47µF/25V，C4/C5/C6=高压瓷片；E=放电电极。

**⚠️ 安全与设计风险（务必阅读）**：
1. **热失控风险**：ZVS 无电流/温度反馈，继电器一旦长时间吸合，线圈与 Q1/Q2 会持续满驱并发热。**单次点火时长必须严格受限**（建议 ≤3~5s，软件层面在 task.lua 里做超时自动关断）。首次试弧用限流电源或短脉冲验证。
2. **触电风险**：C1/C2/C3 位于母线侧、整流后高压可达数千伏，且部分节点对地为高电位——调试期断电后用大功率电阻对 C4/C5/C6 及电极充分放电，人体勿跨越电极回路。
3. **供电轨**：该模块标称 DC12V，**不可直接接 18650(3.7~4.2V)**，否则不起弧或损坏；必须由 MT3608 升压到 12V 供电（见 §2.5）。

### 2.5 供电分支

点火模块需要 **DC12V**，UNO/继电器需要 **5V**，两者电压轨不同——这是相对旧版方案的一个实质改动。有两条实现路径，二选一：

- **方案 A（推荐，双升压）**：一路 MT3608 整定到 **5.0V** 专供 UNO 5V 脚 + 继电器 VCC；另一路升压模块整定到 **12V**，其正极进继电器 COM、NO 出到点火模块 DC12V(+)。控制电与动力电彻底分离，最稳。
- **方案 B（单升压 + 板载 LDO）**：仅一路 MT3608 升到 **12V** 作为动力母线（继电器 COM→NO→点火模块）。UNO 用板载稳压从 12V 自产 5V（**走 UNO 的 VIN/Barrel 口，绝不可把 12V 灌进 5V 脚**）；继电器线圈改由 UNO 板载 5V 脚供电，D7 只驱动三极管/光耦隔离电路。省一颗模块，但要求继电器模块带光耦且线圈电流在 UNO 稳压能力内。

| 端子 | 接到 |
|---|---|
| MT3608-A VIN+/VIN− | 电池 + / 公共 GND ★（经总开关） |
| MT3608-A VOUT+ = 5.0V | UNO 5V 脚 + 继电器 VCC |
| MT3608-B(或同一 12V 母线) VOUT+ = 12V | 继电器 COM（动力电入口） |
| 继电器 NO | 点火模块 DC12V(+) |
| 各模块 GND | 公共 GND ★ |

## 3. 分步装配与上电检查（按序执行，每步有检查点）

> 总原则：**先低压、后高压；先单板、后联机；全程不装 18650，用 USB/桌面电源代供**。★ 记号 = 公共 GND 星点（电池负极处单点汇接，避免高压回路电流流经信号地）。

### 步骤 1：DTU 单板（已完成 ✅）
用 DTU 自身 USB 供电 + YEDTestTools 串口验证（就是你 8/31 凌晨做的部分）。确认天线已接、SIM 槽内卡片 ICCID 正常。

### 步骤 2：UNO 单板（无任何外接线）
1. 仅 USB 供电，`pio run -t upload`（见 §5 PlatformIO）烧录固件。
2. 检查点：上电 LED 灭；按 D2 按键，LED 状态翻转（本地点动切换事件），无蜂鸣提示。
3. 再把 USB-TTL 接 D5（调试口）→ 串口助手 9600 应看到 boot/ready 及按键 JSON 事件。

### 步骤 3：MT3608 整定（**接入 UNO 之前必须做**）
1. MT3608 只接电池正负（或桌面电源 3.7V 模拟），输出空载。
2. 万用表调 VOUT 电位器到 **5.00V ±0.05V**，锁紧。
3. 检查点：拆下电池后复测一次输出仍为 5V（防止电位器松动）。升压模块空载输出可能高达输入电压以上，未整定直插会烧 UNO。

### 步骤 4：低压联机（DTU + UNO + 继电器，不接点火模块）
1. 按 §2.1/2.2/2.3 接线：串口 3 线、D7→IN、5V/GND、DTU VIN←电池+（此时用桌面电源 3.8V 代供）。
2. UNO 改由 5V 轨供电（拔 USB 前先接好 5V，再拔 USB；**5V 脚与 USB 供电不要同时接**）。
3. 检查点：DTU NET LED 正常闪烁；云端/MQTT 测试工具下发 `relay:1`（经任务）→ 听到继电器"咔哒"，LED 亮、调试口打印 `relay=ON`。
4. 上电次序：先 5V 轨（UNO/继电器）后 DTU 均可，但**撤电时先撤动力电（电池总开关）**。

### 步骤 5：12V 动力轨整定（仍不带点火模块）
1. 将升压模块（方案 A 的第二路 / 方案 B 的母线）空载整定到 **12.0V**，锁紧电位器。
2. 手动短接继电器 COM-NO（或下发 relay:1）验证 NO 端出现 12V、relay:0 时为 0V。
3. 检查点：断电后用万用表确认 NO 端对地泄放至 0V。

### 步骤 6：接入点火模块与电极（最后装配）
1. 点火模块 DC12V(+)/GND 接继电器 NO / 公共 GND ★；电极固定在绝缘支架上，间隙先设 **~5mm**（BOM 标注值）。
2. 首次试弧：**在户外或不燃托盘上**、电极朝向无人方向，下发 relay:1，观察起弧后**立即 relay:0（单次 ≤3~5s）**——ZVS 无反馈，长时间通电会过热。
3. 检查点：Q1/Q2 与 T2 磁芯温升（烫手即缩短导通时长或加散热）；电弧稳定。断电后对高压电容充分放电再触碰。

### 步骤 7：正式电池供电
1. 装入 18650（建议带 DW01+8205A 保护板），总开关串在电池+。
2. 复测 §4 全部检查项，记录到 `docs/experiment-log.md`。

## 5. 与固件的对应关系（PlatformIO 工程）
- 固件：`firmware/arduino/arc_remote/`（PlatformIO 工程，`src/main.cpp` + `include/config.h`）
- 引脚定义集中在 `include/config.h`：`RELAY_PIN=7`（继电器驱动）、`DEBUG_TX_PIN=5`（调试口）、`DTU_RST_PIN=6`（预留）。**蜂鸣器已于 v3 移除**（原 D8 不再使用）。
- DTU 侧任务 `firmware/m100pg-c2/task.lua` 已同步去掉 `PerSetDo`（本机无 DO 资源），继电器完全由 UNO 驱动。**下一步阶段 A 建议在 task.lua 增加 relay:1 超时自动关断**，配合点火模块 ZVS 无反馈的过热风险。
- 烧录：`pio run -t upload`（拔 D0/D1）；日志：`pio device monitor` 或 USB-TTL 接 D5 看 9600 调试口
