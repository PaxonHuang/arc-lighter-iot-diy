## 1. 项目概述

### 1.1 应用场景

DIY 个人玩家项目:通过 4G 网络远程控制高压电弧点火装置。可用于:
- 远程点烟/点火演示
- 户外便携点火
- IoT 远程控制技术验证

### 1.2 设备规格

| 参数 | 值 |
|------|-----|
| 输入电源 | 18650 锂电池 1~2 节(3.7V~7.4V) |
| 输出电压 | DC 15~30V(电弧瞬间) |
| 最大功率 | 70W |
| 控制方式 | 4G MQTT 远程 + 本地按键 |
| 远程平台 | 银尔达 IOT 平台 |

### 1.3 项目边界(已确认)

- ✅ DIY 个人玩家,无任何安全冗余设计
- ✅ 不做安全测试、极限测试、燃烧临界点测试
- ✅ 不使用保险丝(用户明确要求)
- ✅ 使用银尔达官方 IOT 平台(替代 EMQX 自建)
- ✅ 简化架构,M100PG-C2 主控直驱继电器

### 3.2 控制流

**远程控制(云端 → 电弧):**

```
银尔达 IOT Web/小程序
   ↓ 触发按钮 "点火"
   ↓ 发布 MQTT: ${IMEI}/cmd
   ↓ JSON: {"cmd":"set_relay","param":{"ch":1,"state":"on"}}
   ↓
M100PG-C2 Lua 任务
   ↓ PronetGetRecChAndDel(1) 收到命令
   ↓ json.decode + 校验
   ↓ PerSetDo(1, 1)          ← GPIO 高电平
   ↓
TONGLING 继电器
   ↓ 5V 线圈吸合
   ↓ COM-NO 闭合
   ↓
XL6009 通电 → 输出 24V → D880 振荡 → 高压电弧
   ↓
M100PG-C2 同时上报: ${IMEI}/tele
   ↓ {"relay1":1,"vbat":3800,"csq":25}
   ↓
银尔达 IOT 平台 → Web 界面实时显示
```

**关闭流程:** state:"off" → PerSetDo(1, 0) → 继电器释放 → 升压断电 → 电弧熄灭

### 3.3 Arduino 协控(简化版)

如果保留 Arduino(可选):
- D2: 本地点动按键 → 拉低时切换继电器
- D4: 状态 LED(继电器吸合时常亮)
- D8: 蜂鸣器(吸合时短鸣 100ms)

**本地点动优先级高于远程**,按下时强制切换,远程命令 1s 后恢复同步。

### 4.2 M100PG-C2 Lua 任务代码

```lua
-- 路径: M100PG-C2 Web 配置平台 → 任务代码编辑
-- 银尔达 IOT 物模型协议自动处理 sset/sget/dup
-- 任务代码负责本地控制逻辑 + 扩展采集

local taskname = "iotArcTask"
log.info(taskname, "start")

PronetStopProRecCh(1)
PerSetDo(1, 0)  -- 初始关闭

local nid = 1
local arcCount = 0

while true do
    -- 处理服务器下发控制 (如果不在物模型下)
    local netr = PronetGetRecChAndDel(nid)
    if netr then
        log.info(taskname, "rx", netr)
        local j = json.decode(netr)
        if j and j.param and j.param.sw1 ~= nil then
            if j.param.sw1 == 1 then
                PerSetDo(1, 1)
                arcCount = arcCount + 1
                -- 通知 Arduino
                UartSetSendCh(1, string.char(0xA5, 0x01, 0x01))
            else
                PerSetDo(1, 0)
                UartSetSendCh(1, string.char(0xA5, 0x01, 0x00))
            end
        end
    end

    -- 周期上报 (5s)
    sys.wait(5000)
    local d = {
        sw1 = PerGetDoSta(1),
        vbat = PerGetVbattV(),
        csq = mobile.csq(),
        arc_count = arcCount
    }
    -- 银尔达物模型协议: 通过 dup 主动上报
    local payload = {"dup", json.encode({param = d})}
    -- 实际使用 PronetSetSendCh 发布
    -- (此处简化为示意,银尔达物模型下数据点会自动同步)
    log.info(taskname, "tele", json.encode(d))
end
```

### 4.3 Arduino 代码(简化版)

```cpp
// 路径: Arduino/sketch/arc_remote/arc_remote.ino
// 本地点动 + LED 指示 + 串口桥接 DTU

#define RELAY_BYPASS_PIN 7   // 不用!DTU 直接控制
#define LOCAL_BTN_PIN 2
#define LED_PIN 4
#define BUZZER_PIN 8

volatile bool btnPressed = false;
void btnISR() { btnPressed = true; }

void setup() {
    Serial.begin(9600);
    pinMode(LOCAL_BTN_PIN, INPUT_PULLUP);
    attachInterrupt(digitalPinToInterrupt(LOCAL_BTN_PIN), btnISR, FALLING);
    pinMode(LED_PIN, OUTPUT);
    pinMode(BUZZER_PIN, OUTPUT);
}

void loop() {
    if (btnPressed) {
        btnPressed = false;
        delay(50); // 消抖
        // 通过串口通知 DTU 切换
        Serial.println("{\"evt\":\"btn_toggle\"}");
        tone(BUZZER_PIN, 2000, 100);
    }

    // 接收 DTU 下行同步命令
    if (Serial.available()) {
        String s = Serial.readStringUntil('\n');
        if (s.indexOf("relay:1") >= 0) {
            digitalWrite(LED_PIN, HIGH);
        } else if (s.indexOf("relay:0") >= 0) {
            digitalWrite(LED_PIN, LOW);
        }
    }
}
```

## 7. 故障排查

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| NET LED 5000ms 闪烁 | SIM 卡不识别 | 检查卡方向、清洁触点 |
| NET LED 100ms 快闪 | 注册网络失败 | 检查 APN、信号覆盖 |
| NET LED 500ms 慢闪 | 没连上服务器 | 检查 MQTT 参数、网络 |
| 继电器不吸合 | doout 无输出 | 检查 Lua 任务是否启动 |
| XL6009 无输出 | 继电器没闭合 | 万用表测 COM-NO 通断 |
| 电弧不产生 | D880 不振荡 | 检查偏置电阻、线圈方向 |
| 电弧太弱 | 升压不足 | 调 XL6009 多圈电位器 |
| Arduino 收不到命令 | 串口接反 | 交换 TX/RX |
