# 实验日志

## 实验 EX-20260726-01

**日期:** 2026-07-26
**目标:** 验证远程开/关功能
**环境:** 室内, 室温 25°C, 4G 信号 CSQ=25

### 实验步骤
1. 上电,DTU 联网,NET LED 1000ms 闪烁
2. 登录银尔达 IOT 平台,切换 sw1=1
3. 观察继电器:1s 内吸合
4. 观察电弧:电极间出现紫色电弧
5. 持续 5s,无异常
6. 切换 sw1=0,电弧熄灭

### 数据记录
- 起始电压: 4100 mV
- 终止电压: 4050 mV (50mV 跌落,符合预期)
- 信号强度: 25
- 继电器吸合时间: `<500ms`
- 电弧长度: `~3mm`

### 结论
✅ 远程点火功能正常
